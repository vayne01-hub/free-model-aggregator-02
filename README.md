A Node 22 server that unifies OpenRouter's free models behind one endpoint speaking both the OpenAI and Anthropic wires. It ranks the free catalog by rating, walks failover when an upstream refuses, and serves each prompt with a single gateway call wherever the upstream allows.

## Run it

```sh
node main.ts # OPENROUTER_API_KEY and MAKEFUN_ENV_URL come from the harness environment
```
